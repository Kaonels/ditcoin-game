     3→## Project Overview
     4→Porting a 5,393-line vanilla-JS Solana-themed multiplayer game ("DITCOIN SOLANA EMPIRE")
     5→into the Next.js 16 sandbox. The user uploaded three files (`index.html`, `server.js`,
     6→`package.json`) and reported two issues:

    10→
    11→## Architecture Decision
    12→The game is a self-contained single-page HTML file (inline CSS + JS, embedded base64
    13→logo). React-ifying 5,393 lines of canvas/DOM code would be wasteful, so we:
    14→- Serve the game as a **static asset** at `/ditcoin.html` (in `public/`).
    15→- Render it full-screen via an **iframe** in `src/app/page.tsx` (the only user route).
    16→- Run a **WebSocket relay mini-service** on port `3003` (`mini-services/ditcoin-ws/`).
    17→- Route the WebSocket through the Caddy gateway using `?XTransformPort=3003`.
